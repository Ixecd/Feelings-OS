# ADR 005: 数据分类流放——冻结 vs 擦除，Post-Mortem 与页回收

> 日期：2026-05-23
> 状态：定稿
> 性质：Feelings-OS 内存管理与故障诊断

---

## 核心原则

趋势已经断了——在噪声上建的楼必须瞬间推倒。但肉身踩过的脚印——一个都不能涂抹。

## 数据分类——原始 vs 衍生

```
原始数据
    心率原始采样序列。皮电原始值。呼吸频率曲线。
    EEG 频段功率。各设备温度。总线 ACK 历史。

    不是 cached 算出来的——是直接从 /dev/* 帧缓冲页抄过来的。
    它们是地面实况。是客观的电生理事实。

衍生数据
    基于原始数据算出来的东西。
    心率趋势梯度。皮电变化预测方向。HRV 谱分布漂移速率。
    卡尔曼滤波的内部协方差矩阵。
    上一帧反馈 → 下一帧参数映射表。

    这些不是地面实况。是假设趋势持续的外推模型。
    趋势断裂 → 在噪声上建的楼 → 必须推倒。
```

## L0-L2 分层处置

| 缓存层级 | 数据类型 | 熔断后处置 | mempoold 微操 |
|---------|---------|-----------|-------------|
| L0 BRAM | 当前帧缓冲 | 保底帧接管 | busd 硬编码重写为安全基线。不经过 cached |
| L1 线程 | 原始数据 | 冻结（RO） | MPU 权限 RW→RO，读保留写禁止 |
| L1 线程 | 衍生数据 | 强解映射 | 物理页回空闲链表 |
| L2 共享 | 原始数据 | 冻结（RO） | MPU 权限 RW→RO |
| L2 共享 | 衍生数据 | 强解映射 | 物理页回收 |

## MPU 偷渡——让 cached 撞墙

cached 不知道自己写权限被拉掉了。它继续没心没肺地执行写入。硬件在总线上直接拦。

```
正常时期
    cached 执行: STR R1, [L1_Raw_Addr] → MPU 允许 → 写入成功

熔断发生
    P0 写入 MPU 配置寄存器 → 对 cached 管理区的写权限全部拉低
    仅需 1 个总线周期

熔断期内
    cached 照常执行: STR R1, [L1_Raw_Addr]
                        │
                        ▼ (硬件直接拦截)
              [ HardFault: 写入违规 ]
                        │
                        ▼
    schedulerd 捕获: "预期中的撞墙——直接 NOP 放行"

cached 不崩溃。数据不污染。
```

优势：cached 的代码里不需要任何"检查熔断状态"的条件分支。不需要在每个循环里判断 `if (system_status == FUSED)`。省掉了分支预测器资源。保证执行时间绝对确定。

## Post-Mortem——离线诊断

慢启动爬坡时，animi 面对的是洁净的虚无。过去的数据对恢复期是毒——但对诊断是金。

```
冻结页里的信息
    心率变异性（HRV）在断裂前第 84 帧是否有异常跳变？
    后颈设备阻抗在 30 秒内是否因出汗连续漂移？
    哪一个从设备最先失联？失联的顺序是什么？

离线诊断进程
    低优先级。系统稳定后才启动。
    只读冻结页。不能写。
    生成诊断报告 → logd 追加 → 哈希链锚定。

意义
    不单是操作系统级的防御——是电生理学意义上的黑匣子。
    每一次熔断的全部原始数据完整保留。
    事后可以完整复盘：真正是什么导致基板差点受到威胁。
```

## 冻结页回收——时机与机制

多熔断几次，冻结页会堆积。mempoold 的空闲链表会被历史尸体吃光。必须回收。

### 回收时机

```
不是熔断时期——保底帧期间不能分心做任何内存管理。
不是在慢启动爬坡期——CPU 全部算力属于总线同步和 animi 校准。

是在系统完全回到闭环之后。
    Epoch 稳定。连续 100 帧无任何异常。
    所有设备在正常强度下正常运行。
```

### 回收角色

```
logd 负责搬运（低优先级后台进程，被 P0-P2 抢占）
    不是"负责擦除"——是"负责搬运到外部存储"。

    1. 检查 mempoold 的冻结页链表
    2. 将冻结页的内容 → 追加写入外部存储（诊断存档）
    3. 写入完成后 → logd 请求 mempoold 释放该页
    4. mempoold 将该物理页 MPU 权限恢复 → 回到空闲链表

回收优先级
    最老的 Epoch 的页先回收。
    最近一次熔断的页最后回收。
    如果一个 Epoch 的冻结页还没被离线诊断读走——
    logd 先搬，诊断读的是搬运后的外部存档。
```

### 回收流程图

```
系统回到闭环
    ↓
logd 后台线程被 P3 调度（只在真的空闲时运行）
    ↓
遍历 mempoold 冻结页链表
    ↓
[ 冻结页 N ] → 追加写入外部存储 → 标记已存档
    ↓
请求 mempoold 释放
    ↓
mempoold 重置该页 MPU 权限 → 回收进空闲链表
    ↓
回到遍历——直到冻结页链表为空
```

## 永不回收的例外

```
静态校准参数持久区
    不在 L1/L2。不在 cached 管理范围。
    在 mempoold 的持久区——单独分配，永不回收。

    二次熔断时——保留但标记去信任化。
    不擦除。不覆盖。不回收。
```
